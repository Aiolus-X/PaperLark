# 个人模型配置

服务运行后打开 [PaperLark 设置](http://127.0.0.1:8787/app)。页面仅允许本机访问，不需要飞书登录。

## 保存和切换

1. 选择预设或填写 API 地址，例如 `https://suwen.chatfold.pro/suwen/v1`。
2. 选择接口类型。Suwen 可从 Chat Completions 开始；支持 Responses 的服务选择 Responses。
3. 填写服务商提供的模型 ID 和 API Key。预设模型只是填写示例，不代表你的账号一定可用。
4. 推理强度可留空，表示不发送该参数；只有服务支持时才选择 `high`、`xhigh` 等值。
5. 首次可不勾选“使用我的模型配置”，先保存并点击“测试已保存配置”。测试使用刚保存的配置，即使它尚未启用。
6. 测试成功后，勾选“使用我的模型配置”并保存。新评论立即生效，已开始的任务继续使用启动时的配置。

取消勾选并保存，或删除自定义 Key，即恢复 `.env` 中的默认模型。现有默认 Key 不会被覆盖。

保存后页面只显示“已保存密钥”，不回显 Key。留空可以保留已保存的 Key；更换 API 地址时需要重新填写对应服务的 Key，避免误发到另一个服务。

## 常见问题

- **HTTP 401**：服务未接受当前 Key；检查凭据有效期、复制是否完整，以及地址是否对应此 Key。PaperLark 不会在配置失败后偷偷改用另一个模型。
- **模型不存在／权限不足**：使用账号实际可调用的模型 ID，不能只看示例名称。
- **不支持 reasoning 参数**：将推理强度设置为“不发送此参数”。
- **服务域名未启用**：把准确域名加入 `.env` 的 `PAPERLARK_LLM_ALLOWED_HOSTS`，逗号分隔，重启服务后再保存。当前 `.env` 的默认模型地址域名也会自动允许。
- **页面已过期**：刷新设置页后重试。更改配置需要同源会话及 CSRF 校验。
- **生成超时**：普通模型请求与文档生成使用不同超时；见 `.env.example`。流式响应未完成时不会发布部分内容。

## 存储和换电脑

默认文件：

| 文件 | 内容 |
| --- | --- |
| `data/model-settings.json` | AES-256-GCM 加密后的自定义配置 |
| `data/model-settings.key` | 本机解密密钥，文件权限为当前用户读写 |
| `.env` | 飞书凭据与默认模型配置 |
| `data/state.json` | 总结关联、任务、阅读记录等个人状态 |

这些文件均不进入 Git。换电脑最简单的方式是克隆代码，重新填写 `.env`，再在设置页输入 Key。若要保留自定义配置，需要通过私人渠道同时迁移加密文件和对应密钥；只复制加密文件无法解密。使用 `PAPERLARK_ENCRYPTION_KEY` 时，需要迁移同一个环境密钥。

PDF 扩展在新电脑上重新运行 `npm run extension:setup` 配对。项目的技能文件不包含任何账号授权、API Key 或浏览器登录状态。
