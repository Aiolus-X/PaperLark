# 论文总结格式

`/doc` 默认使用以下单篇论文分享结构。可通过 `FEISHU_TEMPLATE_URL` 配置自己的参考模板，仅参考结构，不复制模板中的其他论文事实。

1. **TL;DR**：用一两句话说明核心问题、方法和结论。
2. **Motivation**：现有方法的不足、研究问题、为什么值得解决。
3. **Method**：关键机制、数学形式和直觉；以当前论文实际内容为准。
4. **Main Result**：主要实验、设置、结果与消融，明确已报告的数据。
5. **思考**：与其他方法的联系、局限、可能失败的条件、值得验证的想法。AI 推测应明确标出，不冒充用户已有思考。

标题默认使用日期＋论文标题（PDF 优先取可靠元信息或首页标题；可用 `--name` 指定标题）。`/note` 在总结末尾追加原生 ToDo；`/add` 将当前评论讨论整理成后续小节。

原分享模板中的图像和公式截图不会从其他论文复制过来。当前版本生成文字和原生公式，自动提取与插入当前论文图表尚未实现。

输出默认简洁、高信息密度。总结默认约 800–1200 中文字；每节只保留能支撑理解的关键机制、证据、条件和思考，不沿用模板的冗长程度。评论默认更短。翻译保留完整信息，不为了简短丢失原文。
