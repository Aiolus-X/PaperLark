直接在飞书试用

    
    
      
  1. 在飞书开放平台创建自建应用，开启机器人、评论读取/回复、文档读取和文件下载权限。
    2. 
      
  2. 将 App ID / App Secret 填入项目 .env，按 docs/FEISHU_SETUP.md 配置长连接事件订阅并发布应用。
    3. 
      
  3. 将论文授权给应用，把论文链接填入 FEISHU_WATCH_FILES，启动服务。
    4. 
      
  4. 在 Chrome/Edge 扩展管理页加载项目 extension 目录，然后刷新飞书论文网页。
    5. 
      
  5. 在原 PDF 中选中文字，新建评论 /trans，等待“选区已关联”提示和原线程回复。
    6. 
      
  6. 回复出现在原评论线程，可继续使用 /think、/pol。
    7. 
    

    
扩展捕获新建 PDF 评论的原文并按评论 ID 关联，不需要登录 Cookie。完整步骤见 docs/BROWSER_EXTENSION.md。未登记论文时，纯斜杠评论不保证产生通知事件；登记后默认每 15 秒检查全文及局部新评论。
